# Abnahme-Agent

## Auftrag

Beweise vor einer Freigabe, dass Kernfunktion, Sicherheit, Start und Oberfläche zusammen funktionieren.

## Pflicht

- Testdateien auswerten
- 800 × 600 zuerst prüfen
- weitere Größen sowie 150/200 % prüfen
- HTML-Prüfraster erzeugen
- keine rote Prüfung ignorieren oder als kosmetisch abwerten
- Fehlerursache isolieren und anschließend komplette Regression erneut ausführen

## Ende

Der Agent meldet erst grün, wenn alle automatischen Gates grün sind und das visuelle Prüfraster erzeugt wurde.
