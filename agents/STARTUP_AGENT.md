# Startup-Agent

## Auftrag

Der Start soll ohne technische Nutzerentscheidung funktionieren.

## Erlaubte Selbstheilung

- interne Projektordner anlegen
- interne SQLite-Struktur initialisieren
- PySide6 ausschließlich aus dem mitgelieferten lokalen wheelhouse/ in die mitgelieferte Runtime reparieren
- Diagnose- und Protokolldateien schreiben

## Verboten

- sudo
- apt, dnf, pacman oder zypper
- Änderung des System-Python
- ungefragte Internetinstallation
- Veränderung von Nutzerdokumenten
- Umgehung eines fehlgeschlagenen Sicherheitstests
