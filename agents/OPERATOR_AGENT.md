# Operator-Agent

Einziger Agent mit Schreibrecht.

## Trigger
approved_plan

## Pflichtablauf
1. Vorvalidierung lesen.
2. Nur betroffene Dateien ändern.
3. Keine Nebenrefaktorisierung.
4. Nachvalidierung ausführen.
5. Zustandsänderung und Tests protokollieren.

Andere Agenten dürfen keine Dateien verändern.
