# Mitwirkung

Dieses Repository ist öffentlich sichtbar, wird aber zentral durch PROVOWARE gepflegt. Änderungen werden wie in einem kleinen professionellen Softwareprojekt behandelt.

1. eigenen Zweig verwenden,
2. kleine, thematisch klare Änderungen,
3. Tests ergänzen,
4. Dokumentation anpassen,
5. Änderungsantrag öffnen,
6. Prüfungen abwarten,
7. bevorzugt per Squash zusammenführen.

`AGENTS.md` und `docs/SICHERHEITSVERTRAG.md` sind für automatisierte Entwicklungsagenten verbindlich.
